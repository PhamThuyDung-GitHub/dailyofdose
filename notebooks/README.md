## LoRA from scratch — Vietnamese Colab notebook

Open the notebook in Google Colab with this URL pattern:

```text
https://colab.research.google.com/github/<owner>/<repo>/blob/<branch>/notebooks/lora_from_scratch_vi.ipynb
```

If this repository is pushed as `dailyofdose` on the `main` branch, use:

```text
https://colab.research.google.com/github/<owner>/dailyofdose/blob/main/notebooks/lora_from_scratch_vi.ipynb
```

Replace `<owner>` with the GitHub username or organization that hosts the repository. The local checkout used to create this notebook does not define a `git remote`, so the final owner-specific URL cannot be inferred from the repository metadata.
